# Security Policy

Cortex is a personal fork of [Warp](https://github.com/warpdotdev/warp). Most code is inherited from upstream and is best reported there.

- **Cortex-specific code** (anything not in upstream Warp): open a [private advisory](https://github.com/lawsmd/cortex/security/advisories/new) on this repo. Please don't file a public issue.
- **Upstream Warp code**: report via [security@warp.dev](mailto:security@warp.dev) or Warp's [private advisory page](https://github.com/warpdotdev/Warp/security/advisories/new). Fixes flow back into Cortex via regular upstream merges.
